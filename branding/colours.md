# PyreVixen palette

Placeholder palette for the PyreVixen brand. Flat, geometric, original —
deliberately NOT the Firefox orange/purple gradient language.

| Name           | Hex       | Usage                                              |
|----------------|-----------|----------------------------------------------------|
| Haven Night    | `#101828` | Icon/adaptive-icon background, dark UI surfaces    |
| PyreVixen Ember | `#E4572E` | Primary accent, icon mark                          |
| Kindled Gold   | `#F2A541` | Secondary accent, highlights, the haven chevron    |
| Bone           | `#F5F1E6` | Primary text on dark surfaces                      |
| Mist Grey      | `#A8B0BC` | Secondary text on dark surfaces                    |
| Pine           | `#2E5339` | Tertiary — success / positive states               |

## Rules

- Text on Haven Night: use Bone for primary text, Mist Grey for secondary.
  Both clear 4.5:1 contrast against `#101828`.
- The icon mark is flat geometry (hexagon + ears + chevron). No gradients,
  no globe, no fox-tail swirl — nothing that echoes Mozilla's marks.
- If the name changes (see BRANDING.md), the palette can stay: none of the
  colour names reference the placeholder name.
